# KinSim

<p align="center">
  <img src="./images/unifr_logo.svg" alt="University of Fribourg" width="300">
</p>

**PacBio kinetic signal simulator for metagenomic binning.**

KinSim learns species-specific IPD/PW distributions from real PacBio SMRT sequencing data, then injects realistic kinetic signals into synthetic reads generated by PBSIM3. The goal: prove that methylation-derived kinetic signatures improve metagenomic binning.

---

## How it works

PacBio sequencing captures two kinetic signals at every base: **IPD** (Inter-Pulse Duration) and **PW** (Pulse Width). These signals vary depending on the local 11-mer sequence context and DNA methylation state. KinSim exploits this by:

1. **Extracting** raw IPD/PW observations from real PacBio BAMs, keyed by (11-mer, methylation state).
2. **Training** a model that learns the statistical distribution of IPD/PW for each context.
3. **Generating** synthetic signals onto PBSIM3 reads, using the reference genome to resolve context.

Three generation models are available:

| Model | Flag | Method | Status |
|---|---|---|---|
| **Dictionary** | `--model dictionary` | Gaussian sampling from per-kmer accumulators | Implemented |
| **MLP** | `--model mlp` | Supervised MLP predicting N(μ, σ²) per context | Implemented |
| **cGAN** | `--model cgan` | Conditional WGAN-GP for full distribution learning | Implemented |

All models share the same `extract` → `merge` data preparation pipeline and produce identical BAM output (`fi`/`fp` tags).

## Installation

### Recommended (editable install)

```bash
git clone https://github.com/<user>/KinSim.git
cd KinSim
pip install -e .
```

The `kinsim` command is then available system-wide:

```bash
kinsim --version
```

### Without installing

```bash
cd /path/to/KinSim
python -m kinsim --version
```

### Optional dependencies

| Feature | Command |
|---|---|
| MLP + cGAN training/generation | `pip install -e ".[cgan]"` — adds PyTorch ≥ 2.0 and TensorBoard |
| Cluster config parsing | `pip install -e ".[cluster]"` — adds PyYAML |
| EMBOSS fuzznuc (recommended) | `sudo apt install emboss` or `conda install -c bioconda emboss` |

> EMBOSS `fuzznuc` is the primary reference-genome methylation scanner. KinSim falls back to Python regex automatically if it is not installed. Use `--no-fuzznuc` to force regex mode.

## Quick start (3 commands)

```bash
# 1. Extract kinetic samples from real PacBio BAMs
kinsim extract reads.bam "m6A,GATC,1" shard.pkl

# 2. Train an MLP model on the extracted data
kinsim train shard.pkl checkpoints/ --model mlp --epochs 50

# 3. Generate signals onto PBSIM3 reads
kinsim generate pbsim3_output/ checkpoints/checkpoint_epoch50.pt \
    "m6A,GATC,1" output/ --model mlp
```

### `kinsim prepare`

**Function:** Validate and normalize a list of BAM/motif-source pairs into a compact config file. Resolves all motif sources (CSV, REBASE, string) into the unified KinSim motif string format.

**Usage:**
```
kinsim prepare <pairs_file> <output_config>
```

**Arguments:**

| Argument | Description |
|---|---|
| `pairs_file` | Text file with alternating lines: BAM path, motif source |
| `output_config` | Output config file (BAM path + resolved motif string, alternating lines) |

**Options:**

| Flag | Default | Description |
|---|---|---|
| `--min-fraction` | 0.40 | Minimum fraction threshold for PacBio CSV filtering |
| `--min-detected` | 20 | Minimum nDetected threshold for PacBio CSV filtering |

**Input/Output contract:**
```
IN:   pairs_file  (BAM path / motif source / BAM path / motif source / ...)
OUT:  config file (BAM path / KinSim motif string / BAM path / ...)
```

**Example:**
```bash
# pairs.txt:
#   /data/Ecoli.bam
#   /data/Ecoli/motifs.csv
#   /data/Salmonella.bam
#   m6A,GATC,1;m4C,CCWGG,2

kinsim prepare pairs.txt config_strains.txt
```

### `kinsim parse`

**Function:** Parse any motif source — PacBio CSV, REBASE file, or inline string — and print the resolved KinSim motif string. Used to inspect and verify motifs before running a pipeline.

**Usage:**
```
kinsim parse <source> [options]
```

**Arguments:**

| Argument | Description |
|---|---|
| `source` | PacBio `motifs.csv`, REBASE file (auto-detected), or inline string e.g. `"m6A,GATC,1"` |

**Options:**

| Flag | Default | Description |
|---|---|---|
| `--min-fraction` | 0.40 | Minimum fraction filter (PacBio CSV only) |
| `--min-detected` | 20 | Minimum nDetected filter (PacBio CSV only) |
| `--patterns <file>` | — | Write fuzznuc `@pattern` file instead of printing motif string |
| `--no-revcomp` | — | Do not include reverse-complement patterns |

**Input/Output contract:**
```
IN:   any motif source (file or string)
OUT:  KinSim motif string to stdout, or fuzznuc pattern file
```

**Examples:**
```bash
# Parse and print the resolved motif string
kinsim parse /data/Ecoli/motifs.csv
kinsim parse /data/rebase_withrefm.txt
kinsim parse "m6A,GATC,1;m4C,CCWGG,2"

# Generate a fuzznuc pattern file for external use
kinsim parse /data/Ecoli/motifs.csv --patterns ecoli_patterns.txt
```

### `kinsim extract`

**Function:** Scan a real PacBio BAM file, slide an 11-mer window across every read, record raw IPD/PW values per (11-mer, methylation state) context. Uses reservoir sampling to bound memory. Produces one `.pkl` shard per BAM file.

**Usage:**
```
kinsim extract <bam> <motifs> <output.pkl> [options]
```

**Arguments:**

| Argument | Description |
|---|---|
| `bam` | PacBio BAM file with `fi` (IPD) and `fp` (PW) kinetic tags |
| `motifs` | Motif source: PacBio CSV, REBASE file, or inline string |
| `output.pkl` | Output shard file |

**Options:**

| Flag | Default | Description |
|---|---|---|
| `--max-samples` | 10 000 | Max observations per (kmer, meth) key — reservoir sampled |
| `--no-revcomp` | — | Do not scan reverse complement strand for motifs |
| `--min-fraction` | 0.40 | PacBio CSV filter |
| `--min-detected` | 20 | PacBio CSV filter |

**Input/Output contract:**
```
IN:   BAM file (fi/fp tags) + motif source
OUT:  .pkl shard — dict[(kmer_id, meth_id)] → np.ndarray(N, 2)   columns: [IPD, PW]
```

**Example:**
```bash
kinsim extract /data/Ecoli.bam /data/Ecoli/motifs.csv ecoli_shard.pkl \
    --max-samples 10000
```

> Run one `extract` job per BAM, then combine all shards with `kinsim merge`.

### `kinsim merge`

**Function:** Concatenate multiple `.pkl` shards produced by `kinsim extract` into a single master training set. Optionally subsamples per key to keep the file manageable.

**Usage:**
```
kinsim merge <shards_dir> <output.pkl> [options]
```

**Arguments:**

| Argument | Description |
|---|---|
| `shards_dir` | Directory containing `*_cgan.pkl` shard files |
| `output.pkl` | Output master training file |

**Options:**

| Flag | Default | Description |
|---|---|---|
| `--max-samples` | 50 000 | Max observations per key after merging |

**Input/Output contract:**
```
IN:   directory of .pkl shards
OUT:  master.pkl — same format as shards, arrays concatenated per key
```

**Example:**
```bash
kinsim merge shards/ master_data.pkl --max-samples 50000
```

### `kinsim train`

**Function:** Train a kinetic model on the merged dataset. The `--model` flag selects the back-end. All model-specific hyperparameters are passed through after `--model`.

**Usage:**
```
kinsim train <data> <output_dir> --model <dictionary|mlp|cgan> [model options]
```

**Arguments:**

| Argument | Description |
|---|---|
| `data` | BAM file (dictionary) or merged `.pkl` (mlp, cgan) |
| `output_dir` | Directory for checkpoints, logs, and config |
| `--model` | **Required.** `dictionary`, `mlp`, or `cgan` |

**Input/Output contract:**
```
IN:   data file + motif source (dictionary) or .pkl (mlp/cgan)
OUT:  output_dir/
        checkpoint_epochN.pt      model weights + optimizer state
        model_config.json         architecture hyperparameters
        training_log.csv          per-epoch metrics
        runs/                     TensorBoard logs
```

---

#### `--model dictionary`

```bash
kinsim train reads.bam output_dir/ --model dictionary \
    "m6A,GATC,1" [--min-fraction 0.40] [--min-detected 20]
```

Builds a Gaussian accumulator dictionary: `[n, Σipd, Σipd², Σpw, Σpw²]` per (kmer, meth) key.

---

#### `--model mlp`

```bash
kinsim train master_data.pkl checkpoints_mlp/ --model mlp \
    [--epochs 50] [--batch-size 4096] [--lr 1e-3] \
    [--kmer-embed-dim 64] [--hidden-dim 128] \
    [--loss gnll|mse|huber] \
    [--device cuda] [--resume checkpoint_epochN.pt]
```

| Flag | Default | Description |
|---|---|---|
| `--epochs` | 50 | Number of training epochs |
| `--batch-size` | 4096 | Mini-batch size |
| `--lr` | 1e-3 | Adam learning rate |
| `--kmer-embed-dim` | 64 | 11-mer embedding dimension (32 → ~0.5 GB) |
| `--hidden-dim` | 128 | Hidden layer width |
| `--loss` | gnll | `gnll` (Gaussian NLL), `mse`, or `huber` |
| `--device` | cuda | `cuda` or `cpu` |
| `--resume` | — | Resume from checkpoint |

Metrics logged per epoch: `train_loss`, `val_loss`, `mse_ipd`, `mse_pw`, `mae_ipd`, `mae_pw`, `pearson_ipd`, `pearson_pw`.

---

#### `--model cgan`

```bash
kinsim train master_data.pkl checkpoints_cgan/ --model cgan \
    [--epochs 100] [--batch-size 4096] \
    [--lr-g 1e-4] [--lr-d 1e-4] \
    [--noise-dim 32] [--kmer-embed-dim 64] \
    [--n-critic 5] [--lambda-gp 10] \
    [--device cuda] [--resume checkpoint_epochN.pt]
```

| Flag | Default | Description |
|---|---|---|
| `--epochs` | 100 | Number of training epochs |
| `--n-critic` | 5 | Discriminator steps per Generator step |
| `--lambda-gp` | 10 | Gradient penalty weight |
| `--noise-dim` | 32 | Generator noise vector dimension |

Metrics logged per step: `Loss/D`, `Loss/G`, `GP` (gradient penalty).

```bash
tensorboard --logdir checkpoints_cgan/runs
```

### `kinsim generate`

**Function:** Inject kinetic signals into PBSIM3 simulated reads. The `--model` flag selects the back-end. Two input modes are auto-detected based on the first argument.

**Usage:**
```
# Directory mode (all species in one directory):
kinsim generate <pbsim3_dir> <checkpoint> <motifs> <output_dir> \
    --model <dictionary|mlp|cgan> [options]

# Per-genome mode (single species):
kinsim generate <reads.fq.gz> <reads.maf.gz> <ref.fna> <checkpoint> <motifs> <output.bam> \
    --model <dictionary|mlp|cgan> [options]
```

**Arguments (directory mode):**

| Argument | Description |
|---|---|
| `pbsim3_dir` | Directory with species subdirs or flat file layout |
| `checkpoint` | Trained model file (`.pkl` for dictionary, `.pt` for mlp/cgan) |
| `motifs` | Motif source (string, CSV, REBASE, or per-species file) |
| `output_dir` | Directory for output BAM files |
| `--model` | **Required.** `dictionary`, `mlp`, or `cgan` |

**Common options:**

| Flag | Default | Description |
|---|---|---|
| `--device` | cuda | `cuda` or `cpu` (mlp/cgan only) |
| `--batch-reads` | 1000 | Reads per GPU inference batch (mlp/cgan) |
| `--linear` | — | Treat genomes as linear (default: circular) |
| `--no-revcomp` | — | Skip reverse complement strand |
| `--no-fuzznuc` | — | Force Python regex for reference scanning |
| `--deterministic` | — | Return predicted mean μ instead of sampling (mlp only) |

**Input/Output contract:**
```
IN:   PBSIM3 reads (.fq.gz + .maf.gz) + reference FASTA + trained model
OUT:  <species>_kinsim.bam / <species>_mlp.bam / <species>_cgan.bam
      flag=4 (unaligned), fi:B:C (IPD uint8), fp:B:C (PW uint8)
```

**Examples:**
```bash
# Dictionary — directory mode
kinsim generate pbsim3_output/ master_dict.pkl "m6A,GATC,1" injected/ \
    --model dictionary

# MLP — directory mode
kinsim generate pbsim3_output/ checkpoints_mlp/checkpoint_epoch50.pt \
    "m6A,GATC,1" generated_mlp/ --model mlp --device cuda

# cGAN — directory mode
kinsim generate pbsim3_output/ checkpoints_cgan/checkpoint_epoch100.pt \
    /data/Ecoli/motifs.csv generated_cgan/ --model cgan --device cuda

# MLP — single genome
kinsim generate reads.fq.gz reads.maf.gz ref.fna \
    checkpoints_mlp/checkpoint_epoch50.pt "m6A,GATC,1" output.bam \
    --model mlp
```

**Supported PBSIM3 directory layouts (auto-detected):**
```
Species subdirectories (recommended):      Flat layout:
  pbsim3_output/                             pbsim3_output/
    Ecoli/                                     Ecoli.fq.gz
      reads.fq.gz                              Ecoli.maf.gz
      reads.maf.gz                             Ecoli.fna
      Ecoli.fna                                Salmonella.fq.gz  ...
    Salmonella/ ...
```

## End-to-end pipeline

### Dictionary pipeline

```bash
# 0. Simulate reads with PBSIM3
sbatch --array=1-10 slurm_kinsim/pbsim3_simulate.slurm \
    genomes/ pbsim3_output/ /path/to/QSHMM-PACBIO-CCS.model

# 1. Prepare motif config
kinsim prepare pairs.txt config_strains.txt

# 2. Build dictionary shards (one per BAM, parallel on cluster)
#    → kinsim train reads.bam shard/ --model dictionary "motifs"
sbatch --array=1-53 slurm_kinsim/kinsim_train.slurm \
    config_strains.txt shards/ master_dict.pkl

# 3. Merge (auto-triggered by last array task, or manually)
kinsim merge shards/ master_dict.pkl

# 4. Generate signals
kinsim generate pbsim3_output/ master_dict.pkl "m6A,GATC,1" injected/ \
    --model dictionary

# 5. Analyze dictionary coverage (optional)
kinsim analyze master_dict.pkl
```

### MLP pipeline

```bash
# Data preparation (shared with cGAN)
kinsim extract reads.bam "m6A,GATC,1" shard.pkl
kinsim merge shards/ master_data.pkl

# Train
kinsim train master_data.pkl checkpoints_mlp/ --model mlp \
    --epochs 50 --device cuda

# Monitor
tensorboard --logdir checkpoints_mlp/runs

# Generate
kinsim generate pbsim3_output/ checkpoints_mlp/checkpoint_epoch50.pt \
    "m6A,GATC,1" generated_mlp/ --model mlp --device cuda
```

### cGAN pipeline

```bash
# Data preparation (same .pkl as MLP — no re-extraction needed)
kinsim extract reads.bam "m6A,GATC,1" shard.pkl
kinsim merge shards/ master_data.pkl

# Train
kinsim train master_data.pkl checkpoints_cgan/ --model cgan \
    --epochs 100 --device cuda

# Monitor
tensorboard --logdir checkpoints_cgan/runs

# Generate
kinsim generate pbsim3_output/ checkpoints_cgan/checkpoint_epoch100.pt \
    "m6A,GATC,1" generated_cgan/ --model cgan --device cuda
```

## Motif formats

### KinSim motif string (internal format)

Semicolon-delimited entries: `MOD_TYPE,IUPAC_MOTIF,POS[,nDetected[,fraction]]`

```
m6A,GCCGATC,5,3551,0.998;m4C,CCWGG,1,922,0.92;m5C,RGATCY,4,1138,0.76
```

- **MOD_TYPE**: `m6A`, `m4C`, or `m5C`
- **IUPAC_MOTIF**: supports R, Y, W, S, K, M, B, D, H, V, N
- **POS**: 0-based index of the modified base within the motif
- **nDetected**, **fraction**: optional fields (from PacBio CSV)

### Auto-detected motif sources

| Input | Detection rule |
|---|---|
| PacBio `motifs.csv` | file ending in `.csv` |
| REBASE file | any other file path (format auto-detected from content) |
| Inline string | not a file path |
| Per-species file | `species_name\|motif_string` per line |

### REBASE format

Two formats auto-detected from file content:

**Simplified two-column:**
```
GATC    2(6)        # m6A at 1-based position 2
CCWGG   2(5)        # m5C at position 2
```

**Format #19 (withrefm):**
```
RS   GAATTC, ?;
MS   2(6mA);
```

Position notation: `X(Y)` where X is 1-based (positive = forward, negative = bottom strand from 5'), Y is `6` (m6A), `5` (m5C), or `4` (m4C).

## SLURM (HPC cluster)

All scripts are in `slurm_kinsim/`. Use `kinsim_pipeline.sh` to run the complete pipeline from the login node with automatic dependency chaining:

```bash
# Dictionary pipeline
bash slurm_kinsim/kinsim_pipeline.sh dictionary \
    pairs.txt 53 config_strains.txt \
    shards/ master_dict.pkl \
    pbsim3_output/ "m6A,GATC,1" 10 injected/

# MLP pipeline
bash slurm_kinsim/kinsim_pipeline.sh mlp \
    pairs.txt 53 config_strains.txt \
    shards/ master_data.pkl \
    pbsim3_output/ "m6A,GATC,1" 10 generated_mlp/ \
    checkpoints_mlp/

# cGAN pipeline
bash slurm_kinsim/kinsim_pipeline.sh cgan \
    pairs.txt 53 config_strains.txt \
    shards/ master_data.pkl \
    pbsim3_output/ "m6A,GATC,1" 10 generated_cgan/ \
    checkpoints_cgan/
```

**Step-by-step SLURM jobs:**

```bash
sbatch slurm_kinsim/kinsim_prepare.slurm         pairs.txt config_strains.txt
sbatch --array=1-53 slurm_kinsim/kinsim_train.slurm   # dictionary shards
sbatch slurm_kinsim/kinsim_merge.slurm                # merge shards
sbatch --array=1-10 slurm_kinsim/kinsim_inject.slurm  # dictionary generate

sbatch --array=1-53 slurm_kinsim/kinsim_cgan_extract.slurm  # extract samples
sbatch slurm_kinsim/kinsim_cgan_train.slurm                  # train cGAN
sbatch --array=1-10 slurm_kinsim/kinsim_cgan_generate.slurm # generate

sbatch slurm_kinsim/kinsim_mlp_train.slurm                   # train MLP
sbatch --array=1-10 slurm_kinsim/kinsim_mlp_generate.slurm  # generate
```

## Output BAM format

All three models produce structurally identical BAM files:

| Field | Value |
|---|---|
| `FLAG` | `4` — unaligned read |
| `fi:B:C` | IPD per base, uint8 `[0, 255]`, length = read length |
| `fp:B:C` | PW per base, uint8 `[0, 255]`, length = read length |
| Header | `HD VN:1.6 SO:unknown` |

N-context positions (first/last 5 bases of reads without reference alignment) receive a default signal of `1`.
