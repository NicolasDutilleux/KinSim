# requirements.lock.txt — exact versions used to train and validate
# the production KinSim model (v0.4.0+).
#
# This file is meant to be regenerated from the cluster `kinsim_env`
# conda environment at the commit that produced the checkpoint. To
# refresh:
#
#     ssh ndutilleux@login8.ibu.unibe.ch
#     conda activate kinsim_env
#     pip freeze > requirements.lock.txt
#
# A reviewer can reproduce the env with:
#
#     python -m venv .venv && . .venv/bin/activate
#     pip install -r requirements.lock.txt
#     pip install -e .
#
# Notes:
#   - PyTorch wheel index depends on the local CUDA stack — the cluster
#     uses CUDA 12.1 wheels. For CPU-only reproduction strip the
#     `+cu121` suffix or pin from `https://download.pytorch.org/whl/cpu`.
#   - EMBOSS fuzznuc (used by `kinsim.utils.motifs`) is a system binary,
#     not a Python package. Cluster build: EMBOSS 6.6.0.
#   - SMRT-Tools (`ccs-kinetics-bystrandify`, `ipdSummary`, `pbmm2`,
#     `jasmine`) are routed through the SMRTlink 25.1 apptainer; not
#     installable via pip.
#
# Until refreshed from the cluster, the only authoritative version
# constraints are in pyproject.toml.
